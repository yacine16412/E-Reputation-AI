# Models

The fine-tuned model weights used by E-Reputation AI are not included in this repository because of their large storage requirements.

## Models used

- DistilBERT — sentiment classification
- FLAN-T5 — recommendation generation
- `all-MiniLM-L6-v2` — semantic similarity
- Regex and keyword matching — preprocessing and aspect detection
